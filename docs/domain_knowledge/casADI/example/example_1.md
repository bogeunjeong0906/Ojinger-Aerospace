# [문제 정의서] 1차원 수직 로켓 착륙/도달 최적화 솔버 개발

## 1. 개요
초기 고도와 속도를 가진 로켓이 목표 시간(Tf) 내에 목표 고도(h_goal)에 속도 0으로 도달하기 위한 최적의 스로틀 곡선을 계산한다. 

## 2. 물리 모델 및 동역학 (System Dynamics)
상태 변수 $x = [h, v, m]^T$ (고도, 속도, 질량)와 제어 변수 $u = [throttle]$ ($0 \le u \le 1$)에 대해 다음 미분 방정식을 따른다.
- $\dot{h} = v$
- $\dot{v} = (u \cdot F_{max} / m) - g$
- $\dot{m} = -(u \cdot F_{max}) / (I_{sp} \cdot g_0)$
*단, $g$와 $g_0$는 $9.80665$로 가정하며, 공기 저항(Drag) 모델은 선택적으로 포함할 수 있다.*

## 3. 최적화 구성 및 제약 조건 (Optimization Constraints)
- **수치 기법:** CasADi `Opti` 인터페이스를 사용한 **다중구간 슈팅법(Multiple Shooting)**을 적용할 것.
- **구간 분할:** 전체 시간 $T_f$를 $N=50$ 이상의 구간으로 나눌 것.
- **적분기:** 각 구간의 연속성(Continuity) 제약을 위해 **4차 런게-쿠타(RK4)** 적분기를 반드시 구현하여 사용할 것 (Forward Euler 금지).
- **경계 조건 (Boundary):**
  - $t=0$: $h=0, v=0, m=m_{initial}$
  - $t=T_f$: $h=h_{goal}, v=0$ (정밀한 도달)
- **물리적 범위 (Bounds):**
  - $0 \le u \le 1$ (스로틀 범위 제한)
  - $m > 0$ (연료 고갈 방지, 최소 질량 설정)
  - $h \ge 0$ (지면 충돌 방지)

## 4. 비용 함수 (Cost Function)
목적 함수는 다음의 가중합으로 구성한다.
- **연료 소모 최소화:** $m_{initial} - m_{final}$
- **제어 부드러움:** $\sum u^2$ (급격한 스로틀 변화 방지)
- 가중치 $w$를 통해 연료와 시간/부드러움 간의 균형을 조절할 수 있도록 설계할 것.

## 5. 코드 구현 요구사항
- **데이터 정합성:** 초기 추측값(Initial Guess) 설정 시 `set_initial`을 사용하여 상태 변수와 제어 변수의 차원을 정확히 매칭할 것.
- **솔버 설정:** `ipopt`를 사용하며, 옵션에서 `nlp_scaling_method: 'gradient-based'`를 활성화하여 수치적 안정성을 확보할 것.
- **결과 출력:** 계산 완료 후 시간, 고도, 속도, 스로틀 정보를 포함하는 딕셔너리를 반환하고 `matplotlib`을 이용한 시각화 코드를 포함할 것.
