kOS-Ferram - Cheat Sheet

1) Core Intent

FAR(Ferram Aerospace Research)의 공력 상태값과 예측 메서드를 kOS에서 ADDONS:FAR:* suffix로 읽어, 비행 제어 및 공력 튜닝에 활용한다.

2) Safety Critical Notes

  • FAR 미설치 또는 비활성 상태에서 ADDONS:FAR:* 접근 시 실패할 수 있으므로 가용성 확인을 먼저 수행한다.
  • AEROFORCEAT(alt, vel)는 현재 자세를 기준으로 계산하므로, 미래 자세 예측에 그대로 쓰면 오차가 발생할 수 있다.
  • 공력값은 비행 상태에 따라 급변하므로 고정 주기(WAIT 0.1 등)로 재조회해야 한다.

3) Snippet Pack (Directly Usable)

// FAR availability check
IF NOT ADDONS:FAR:ISAVAILABLE {
  PRINT "FAR addon not available".
  RETURN.
}.

// telemetry loop from kosferramtest.ks
UNTIL FALSE {
  PRINT ROUND(ADDONS:FAR:IAS, 2) + "   " AT (0,1).
  PRINT ROUND(ADDONS:FAR:MACH, 2) + "   " AT (0,2).
  PRINT ROUND(ADDONS:FAR:CL, 2) + "   " AT (0,3).
  PRINT ROUND(ADDONS:FAR:CD, 2) + "   " AT (0,4).
  PRINT ROUND(ADDONS:FAR:DYNPRES, 2) + "   " AT (0,5).
  PRINT ROUND(ADDONS:FAR:REFAREA, 2) + "   " AT (0,6).
  PRINT ROUND(ADDONS:FAR:TERMVEL, 2) + "   " AT (0,7).
  PRINT ROUND(ADDONS:FAR:AOA, 2) + "   " AT (0,8).
  PRINT ROUND(ADDONS:FAR:AOS, 2) + "   " AT (0,9).

  PRINT ROUND(ADDONS:FAR:AEROFORCEAT(SHIP:ALTITUDE, SHIP:VELOCITY:SURFACE):MAG, 2) + "   " AT (0,11).
  PRINT ROUND(ADDONS:FAR:AEROFORCE:MAG, 2) + "   " AT (0,12).
  PRINT ROUND(ADDONS:FAR:AEROTORQUE:MAG, 2) + "   " AT (0,13).

  WAIT 0.1.
}.

4) Tuning / Parameters

// evaluate expected aero force at candidate flight condition
SET candidateAlt TO SHIP:ALTITUDE + 1000.
SET candidateVel TO SHIP:VELOCITY:SURFACE.
SET predictedForce TO ADDONS:FAR:AEROFORCEAT(candidateAlt, candidateVel).

// simple AoA guard for ascent profile
IF ABS(ADDONS:FAR:AOA) > 7 {
  LOCK THROTTLE TO 0.7.
} ELSE {
  LOCK THROTTLE TO 1.0.
}.

5) Suffix and Key Inventory (No-loss policy)

  • ADDONS:FAR:ISAVAILABLE
  • ADDONS:FAR:IAS
  • ADDONS:FAR:MACH
  • ADDONS:FAR:CL
  • ADDONS:FAR:LIFTCOEF
  • ADDONS:FAR:CD
  • ADDONS:FAR:DRAGCOEF
  • ADDONS:FAR:DYNPRES
  • ADDONS:FAR:REFAREA
  • ADDONS:FAR:TERMVEL
  • ADDONS:FAR:AOA
  • ADDONS:FAR:ANGLEOFATTACK
  • ADDONS:FAR:AOS
  • ADDONS:FAR:SIDESLIP
  • ADDONS:FAR:AEROFORCE
  • ADDONS:FAR:AEROTORQUE
  • ADDONS:FAR:AEROFORCEAT(ALTITUDE,VELOCITY)
  • SHIP:ALTITUDE
  • SHIP:VELOCITY:SURFACE

6) Agent Usage Hints

  • 대기권 비행 제어에서는 AOA, DYNPRES, AEROFORCE:MAG를 함께 읽어 스로틀/피치 제한식을 구성한다.
  • AEROFORCEAT는 탐색(what-if) 계산 용도로 사용하고 실제 제어 입력은 현재 측정값(AEROFORCE, AEROTORQUE) 기반으로 보정한다.
