kOS.MechJeb2.Addon - Cheat Sheet

1) Core Intent

MechJeb2 자동조종과 정보 아이템을 kOS suffix로 직접 접근해 Ascent 제어, Vessel 상태 조회, Delta-V/Target 텔레메트리 조회를 통합한다.

2) Safety Critical Notes

  • MechJeb2 미설치 또는 core 미동작 상태에서 wrapper 접근 시 예외가 날 수 있으므로 ADDONS:MJ:AVAILABLE 및 ADDONS:MJ:CORE:RUNNING을 먼저 확인한다.
  • kOS 조향/스로틀 제어와 MechJeb 자동조종을 동시에 켜면 제어 충돌이 발생할 수 있다. 권한 우선순위를 명확히 분리한다.
  • Ascent 파라미터(DESIREDALTITUDE, TURN*, LIMITQA*)는 autopilot enable 전에 설정하고, 비행 중 변경 시 짧은 주기로 검증한다.

3) Snippet Pack (Directly Usable)

// --- availability / core ---
SET mj TO ADDONS:MJ.
IF NOT mj:AVAILABLE {
  PRINT "MJ addon unavailable".
  RETURN.
}.
SET core TO mj:CORE.
IF NOT core:RUNNING {
  PRINT "MJ core not running".
  RETURN.
}.

// --- wrappers ---
SET v TO mj:VESSEL.
SET info TO mj:INFO.
SET asc TO mj:ASCENT.

// --- ascent guidance setup ---
SET asc:DESIREDALTITUDE TO 100000.
SET asc:DESIREDINCLINATION TO 0.
SET asc:TURNSTARTALTITUDE TO 1500.
SET asc:TURNENDALTITUDE TO 70000.
SET asc:TURNSHAPEEXPONENT TO 0.4.
SET asc:LIMITAOA TO TRUE.
SET asc:MAXAOA TO 5.
SET asc:LIMITQAENABLED TO TRUE.
SET asc:LIMITQA TO 45000.
SET asc:AUTOSTAGE TO TRUE.
SET asc:SKIPCIRCULARIZATION TO FALSE.
SET asc:ENABLED TO TRUE.

// --- vessel/info telemetry ---
PRINT "Q: " + v:DYNAMICPRESSURE.
PRINT "Mach: " + v:MACH.
PRINT "Surface speed: " + v:SPEEDSURFACE.
PRINT "Total DV(vac): " + info:TOTALDVVAC.
PRINT "Stage DV(vac): " + info:STAGEDELTAVVAC.
PRINT "Target dist: " + info:TARGETDISTANCE.

4) Tuning / Parameters

// dynamic ascent retuning loop
UNTIL NOT asc:ENABLED {
  // keep AoA and dynamic pressure constraints active
  IF v:AOA > asc:MAXAOA {
    SET asc:CORRECTIVESTEERING TO TRUE.
    SET asc:CORRECTIVESTEERINGGAIN TO 1.2.
  }.

  IF v:DYNAMICPRESSURE > asc:LIMITQA {
    // reduce acceleration pressure load via MJ limit
    SET asc:LIMITQAENABLED TO TRUE.
  }.

  WAIT 0.1.
}.

// read aliases from wrappers
PRINT info:TDV.      // TOTALDVVAC alias
PRINT info:STWR.     // SURFACETWR alias
PRINT v:SURFVEL.     // SPEEDSURFACE alias

6) Agent Usage Hints

  • 초기화 단계에서 AVAILABLE와 RUNNING 체크를 통과하지 못하면 wrapper 접근 로직을 즉시 중단한다.
  • Ascent 자동화는 설정 단계와 활성화 단계를 분리하고, 활성화 후에는 read-only 텔레메트리 루프로 검증하는 패턴이 안정적이다.
  • 테스트 스크립트의 assert/runner 코드는 치트시트에서 제외하고 실제 API 호출 패턴만 사용한다.
