Atmosphere

1) Core Intent

A Structure closely tied to Body . A variable of type Atmosphere contains information about the atmosphere (or lack of atmosphere) of a celestial body.

2) Safety Critical Notes

⚠ Warning: Previous versions returned this value in KiloPascals by mistake, which has now been changed to Atmospheres.
