DeltaV

1) Core Intent

A DeltaV contains information about the delta-V numbers the stock KSP game calculates for you in the user interface (in the staging list display). There are in fact two different kinds of DeltaV structures in kOS - one that refers to the whole veseel, or one that refers to just one stage of the vessel.

3) Snippet Pack

PRINT "Vessel's total dV number is " + SHIP:DELTAV:CURRENT.

PRINT "The Current Stage dV number is " + SHIP:STAGEDELTAV(SHIP:STAGENUM):CURRENT.
PRINT "The Next Stage dV number is " + SHIP:STAGEDELTAV(SHIP:STAGENUM-1):CURRENT.
PRINT "The Next Stage dV number is " + SHIP:STAGEDELTAV(SHIP:STAGENUM-2):CURRENT.
//
// etc..  Stages number downward from SHIP:STAGENUM to 0, just like
//        in the user interface stage list display.

5) Suffix and Key Inventory

  • DURATION
  • FORCECALC
  • SHIP:DELTAV
