VesselSensors

1) Core Intent

When you ask a Vessel to tell you its Vessel:SENSORS suffix, it returns an object of this type. It is a snapshot of sensor data taken at the moment the sensor reading was requested.

5) Suffix and Key Inventory

  • VESSEL:SENSORS

6) Agent Usage Hints

ℹ Note: These values are only enabled if you have the proper type of sensor on board the vessel. If you don’t have a thermometer, for example, then the :TEMP suffix will always read zero.
