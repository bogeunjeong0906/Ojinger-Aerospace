Path

1) Core Intent

Represents a path. Contains suffixes that can be helpful when using and manipulating paths. You can use path() to create new instances.

3) Snippet Pack

set p to path("0:/home").
set p2 to p:combine("d1", "d2", "file.ks").
print p2
