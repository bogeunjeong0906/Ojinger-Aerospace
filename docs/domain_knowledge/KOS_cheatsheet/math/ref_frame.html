Reference Frames

1) Core Intent

This page describes the \((x,y,z)\) reference frame used for most of kOS ’s vectors. kOS inherits its reference frame mostly from the base Kerbal Space Program game itself. The coordinate system of Kerbal Space Program does some strange things that don’t make a lot of sense at first. The name of the reference frame in which the origin point is CPU Vessel (SHIP) , and the rotation is identical to KSP ’s native raw coordinate grid.

6) Agent Usage Hints

ℹ Note: Be aware that Kerbal Space program (and in fact many of the games based on the Unity game engine) uses a LEFT-handed coordinate system. kOS inherits this behavior from KSP.
ℹ Note: It is hoped that this may be expanded in the future, and conversion routines provided to let people pick a reference frame that makes sense depending on what the script is trying to do. At the moment the only reference frames used are SHIP-RAW and SOI-RAW, as they match closely to what KSP is using internally.
