kOS 터미널 자동 오픈 - Cheat Sheet

1) Core Intent

kOS CPU가 실행 중일 때 스크립트에서 터미널 GUI를 강제로 열어 상호작용을 시작한다.

2) Safety Critical Notes

  • kOSProcessor 모듈명이 다른 커스텀 파트에서는 GETMODULE("kOSProcessor") 호출이 실패할 수 있다.
  • 무한 루프에서 반복 호출하면 UI가 지속적으로 포커스를 점유할 수 있으므로 초기화 시점 1회 호출을 권장한다.

3) Snippet Pack (Directly Usable)

// open kOS terminal from current CPU part
CORE:PART:GETMODULE("kOSProcessor"):DOEVENT("Open Terminal").

4) Tuning / Parameters

// module/event names are string keys and should match part module definition
SET moduleName TO "kOSProcessor".
SET eventName TO "Open Terminal".
CORE:PART:GETMODULE(moduleName):DOEVENT(eventName).

5) Suffix and Key Inventory (No-loss policy)

  • CORE:PART
  • CORE:PART:GETMODULE
  • DOEVENT("Open Terminal")

6) Agent Usage Hints

  • 터미널 입력이 필요한 테스트 러너 실행 직전에 호출하면 입력 대기 상태를 명확히 확인할 수 있다.
  • 실패 가능성을 줄이려면 모듈 존재 여부를 먼저 체크하는 헬퍼 루틴과 함께 사용한다.
