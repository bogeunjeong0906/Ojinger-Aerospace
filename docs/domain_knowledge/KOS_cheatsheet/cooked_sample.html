Cooked Control - Cheat Sheet (Sample)

1) Core Intent

Cooked control means: script sets a target and kOS autopilot continuously drives steering/throttle. Primary interfaces are LOCK THROTTLE, LOCK STEERING, LOCK WHEELTHROTTLE, LOCK WHEELSTEERING.

2) Safety Critical Notes

  • If CONFIG:SUPPRESSAUTOPILOT is true, cooked controls on this page do not take effect.
  • Do not use SAS together with LOCK STEERING.
  • Do not run WAIT (or slow logic) inside cooked LOCK expressions because they execute every physics tick and can starve script CPU time.
  • When done, explicitly free controls with UNLOCK STEERING. and UNLOCK THROTTLE.

3) Snippet Pack (Directly Usable)

// throttle lock: expected range [0.0 .. 1.0]
LOCK THROTTLE TO 0.5.

// steering targets (direction/heading/vector)
LOCK STEERING TO UP + R(20,0,0).
LOCK STEERING TO HEADING(180, 30).
LOCK STEERING TO (-1) * SHIP:VELOCITY:SURFACE.
LOCK STEERING TO VCRS(SHIP:VELOCITY:ORBIT, BODY:POSITION).
LOCK STEERING TO "kill".

// rover-specific cooked controls
LOCK WHEELTHROTTLE TO 0.2.
LOCK WHEELSTEERING TO 45.

// unlock when manual control is needed
UNLOCK STEERING.
UNLOCK THROTTLE.

4) Tuning Snippet Pack (SteeringManager)

// faster turning, possible overshoot increase
SET STEERINGMANAGER:MAXSTOPPINGTIME TO 10.

// rotational velocity PID tuning
SET STEERINGMANAGER:PITCHPID:KP TO 0.85.
SET STEERINGMANAGER:PITCHPID:KI TO 0.5.
SET STEERINGMANAGER:PITCHPID:KD TO 0.1.

// torque response smoothing
SET STEERINGMANAGER:PITCHTS TO 10.
SET STEERINGMANAGER:ROLLTS TO 5.

6) Agent Usage Hints

  • Preferred retrieval keys: LOCK STEERING, UNLOCK STEERING, WAIT warning, MAXSTOPPINGTIME.
  • When generating code, always include an unlock path at script end or abort handling.
  • For atmosphere aircraft, cooked steering may be suboptimal; consider raw steering for precise behavior.
