kOS-KerbalEngineer - Cheat Sheet

1) Core Intent

Kerbal Engineer Redux에서 계산한 burn time, suicide burn, TWR, thermal 지표를 kOS에서 즉시 읽어 비행 로직에 반영한다.

2) Safety Critical Notes

  • Kerbal Engineer 모드가 없으면 ADDONS:KE:* 접근이 실패할 수 있다.
  • BurnTime 계열 값은 실시간으로 갱신되므로 burn 루프 안에서 재계산 없이 캐시하면 오차가 커진다.

3) Snippet Pack (Directly Usable)

// next node half-burn time
SET bt TO ADDONS:KE:NODEHALFBURNTIME.
PRINT bt.

// full node burn time
SET fullBurn TO ADDONS:KE:NODEBURNTIME.
PRINT fullBurn.

// suicide burn telemetry
PRINT ADDONS:KE:SUICIDEBURNCOUNTDOWN.
PRINT ADDONS:KE:SUICIDEBURNDELTAV.
PRINT ADDONS:KE:SUICIDEBURNLENGTH.
PRINT ADDONS:KE:SUICIDEBURNDISTANCE.
PRINT ADDONS:KE:SUICIDEBURNALTITUDE.

// TWR and thermal criticals
PRINT ADDONS:KE:ACTUALTWR.
PRINT ADDONS:KE:TOTALTWR.
PRINT ADDONS:KE:CRITICALPARTNAME.
PRINT ADDONS:KE:CRITICALTHERMALPERCENTAGE.

// version
PRINT ADDONS:KE:VERSION.

4) Tuning / Parameters

// use half-burn value for node-centered burn timing
SET halfBurn TO ADDONS:KE:NODEHALFBURNTIME.
SET burnStartUT TO NEXTNODE:ETA - halfBurn.

UNTIL TIME:SECONDS >= burnStartUT {
  WAIT 0.1.
}.

// update continuously during burn for better cutoff
UNTIL ADDONS:KE:NODEBURNTIME <= 0 {
  LOCK THROTTLE TO 0.35.
  WAIT 0.05.
}.
UNLOCK THROTTLE.

6) Agent Usage Hints

  • 정밀 기동에서는 NODEHALFBURNTIME를 우선 사용하고, burn 중에는 NODEBURNTIME를 짧은 간격으로 재조회한다.
  • 재진입/착륙 자동화에서는 SUICIDEBURN*와 CRITICALTHERMALPERCENTAGE를 동시에 사용해 스로틀 제한 조건을 만든다.
